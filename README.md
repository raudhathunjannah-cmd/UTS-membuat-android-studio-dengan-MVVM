Marketing Campaign

Aplikasi Android Marketing Campaign merupakan aplikasi untuk mengelola data kampanye pemasaran. Aplikasi ini dibuat sebagai proyek UTS dengan menerapkan arsitektur MVVM (Model-View-ViewModel).

Fitur Aplikasi

1. Login 
   
   - Pengguna masuk menggunakan email dan password.
   - email : admin@xample.com dan password : 123
     

2. Daftar Kampanye
   
   - Menampilkan daftar kampanye pemasaran.
   - Menampilkan kode kampanye, jenis promosi, anggaran, dan status kampanye.

3. Detail Kampanye
   
   - Menampilkan informasi kampanye secara lengkap.
   - Meliputi kode, nama, jenis promosi, deskripsi, tanggal mulai, tanggal selesai, anggaran, dan status.

4. Tambah Kampanye
   
   - Menambahkan data kampanye baru.
   - Mengisi kode kampanye, nama kampanye, jenis promosi, deskripsi, tanggal, anggaran, dan status.

5. Logout
   
   - Pengguna dapat keluar dari aplikasi.

Proyek ini dibuat untuk memenuhi tugas Ujian Tengah Semester (UTS).
