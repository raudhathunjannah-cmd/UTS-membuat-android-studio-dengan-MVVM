Marketing Campaign

Aplikasi Android Marketing Campaign merupakan aplikasi untuk mengelola data kampanye pemasaran. Aplikasi ini dibuat sebagai proyek UTS dengan menerapkan arsitektur MVVM (Model-View-ViewModel).

Fitur Aplikasi

1. Login 

   - Pengguna masuk menggunakan email dan password.
   - email : admin@xample.com dan password : 123

   - Menampilkan daftar kampanye pemasaran.
   - Menampilkan kode kampanye, jenis promosi, anggaran, dan status kampanye.
